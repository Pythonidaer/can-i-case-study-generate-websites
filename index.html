Homepage observations · October 27, 2026 · Desktop viewport: 1363 CSS px

Availability covers the primary fonts documented in each study. “All” requires every listed font to qualify. Free means commercial use is permitted under the linked license; trials and personal-use-only downloads do not qualify.

How to read these studies

Each card opens a study of purpose, font selection, hierarchy, spacing, and reading conditions. Font names and values come from browser-computed CSS on sampled homepage elements. Commentary explains what those choices may communicate.

These are independent observations, not official style guides. Values describe one desktop snapshot, not an exhaustive type scale or responsive specification. A declared font stack does not prove which font file rendered every glyph. Font availability was checked separately against linked sources. Font-file identity, mobile typography, contrast ratios, and assistive technology were not audited.
