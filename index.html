How to read these studies

Each card opens a study of purpose, font selection, hierarchy, spacing, and reading conditions. Font names and values come from browser-computed CSS on sampled homepage elements. Commentary explains what those choices may communicate.

These are independent observations, not official style guides. Values describe one desktop snapshot, not an exhaustive type scale or responsive specification. A declared font stack does not prove which font file rendered every glyph. Mobile typography, font licensing, contrast ratios, and assistive technology were not audited.

Framework: Pythonidaer/typography-learning, especially Choosing type for a design and Vocabulary.
