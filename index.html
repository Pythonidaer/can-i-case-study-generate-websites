Website typography studies

How to read these studies

Each study reconstructs a typography guide from selected pages or sections: fonts, text roles, sizes, font weights, line heights, letter spacing, and text widths. Links in the analysis return to the measured roles.

These are independent observations, not official brand specifications. Measurements are grouped by page and actual browser viewport. This review covers desktop rendering; mobile and tablet samples remain pending. CSS evidence can explain implementation but does not replace rendered checks. Font names can be aliases, and availability sources describe reuse conditions without proving the exact font file used. Interpretations explain possible reading effects; accessibility conformance was not audited.

Framework: Pythonidaer/typography-learning, especially Choosing type for a design and Vocabulary.
